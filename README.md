# STI Clinical Workbench

Privacy-first clinician decision-support prototype for structured STI screening, syndrome categorization, exposure-site testing, treatment pathways, partner management and follow-up.

## Clinical sources

- Attached STI screening reference (baseline)
- WHO STI guidelines (2024 treatment updates; 2025 asymptomatic STI guidance)
- CDC STI Treatment Guidelines and screening recommendations
- NACO STI/RTI services for Indian program context

The app does not diagnose or replace examination, laboratory confirmation, local resistance data, or national protocols.

## Local development

```bash
npm install
npm run dev
```

## Deploy

Vercel detects Vite automatically. Build command: `npm run build`; output directory: `dist`.
